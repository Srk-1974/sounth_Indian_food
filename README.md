# South Indian Food App

A beautiful React application for ordering South Indian food, featuring a glassmorphism design, shopping cart, and UPI QR code payment simulation.

## Project Location
This project is located at:
`C:\Users\sriram\.gemini\antigravity\scratch\south-indian-food-app`

## Prerequisites
- Node.js installed on your machine.

## How to Run Locally

1.  **Open Terminal**: Open your command prompt or PowerShell.
2.  **Navigate to Folder**:
    ```bash
    cd "C:\Users\sriram\.gemini\antigravity\scratch\south-indian-food-app"
    ```
3.  **Install Dependencies** (First time only):
    ```bash
    npm install
    ```
4.  **Start the Server**:
    ```bash
    npm run dev
    ```
5.  **Open in Browser**:
    Click the link shown in the terminal (usually `http://localhost:5173/`).

## Features
- **Login**: Enter any username/password.
- **Menu**: View items, add new items, delete items.
- **Cart**: Add items to cart, view total.
- **Payment**: Checkout with a simulated Credit Card or scan a real UPI QR code.

## Saving Changes
All files are saved automatically to the disk. If you edit the code in an editor like VS Code, just save the file (Ctrl+S), and the browser will auto-reload with the changes.

## Running on Another System (No Antigravity needed)
This is a standard **Node.js + React** application. You can run it on *any* computer (Windows, Mac, Linux).

1.  **Copy the Folder**: Copy the entire `south-indian-food-app` folder to the new computer.
2.  **Install Node.js**: Download and install Node.js from [nodejs.org](https://nodejs.org/) on the new computer.
3.  **Open Terminal**: Open a terminal inside the copied folder.
4.  **Install Dependencies**: Run `npm install`.
5.  **Start App**: Run `npm run dev`.
